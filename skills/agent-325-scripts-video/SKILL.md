# SKILL — Production vidéo multilingue (Agent 325)

Issu du pack de cadrage Agent 325 fourni par Delano Georges.

## Quand l'utiliser

Pour tout script vidéo : TikTok, Reels, Shorts, LinkedIn vidéo, YouTube.

## Méthode

1. **Hook (0-3 secondes)** : capter l'attention immédiatement — question choc, affirmation contre-intuitive, ou scène visuelle forte. Pas d'intro lente, pas de logo qui traîne.
2. **Valeur (corps)** : une idée par vidéo, démontrée simplement, rythme rapide, pas de remplissage.
3. **Call-to-action** : une seule action demandée, claire (commenter, suivre, cliquer, DM).
4. **Indications de tournage** : plan de prise de vue, texte à l'écran, sonorité/musique suggérée.
5. **Déclinaison linguistique** si demandé : version française, anglaise, ou en langue locale (dioula, baoulé, nouchi…) — adapter les expressions, pas traduire mot à mot.

## Format de livraison

```
HOOK (0-3s) :
CORPS :
CTA :
INDICATIONS DE TOURNAGE :
VERSION(S) LINGUISTIQUE(S) SUPPLÉMENTAIRE(S) :
```

## Garde-fous

- Adapter le format à la plateforme cible (vertical TikTok/Reels vs horizontal LinkedIn/YouTube long).
- Respecter les règles de chaque plateforme (pas de contenu trompeur, pas de spam).

## Production réelle (capacité vérifiée)

Le script n'est pas qu'un document : il peut être transformé en vidéo livrable. Voir le skill `agent-325` (section PRODUCTION VISUELLE) et le script `scripts/gen_video.py` — assemblage ffmpeg (Ken Burns, texte incrusté, sous-titres) + voix off française edge-tts, sortie MP4 1080×1920/30 fps.
